# WC-DigiClub-Site
Make any changes you want. Make the website your own. Just follow these simple rules ;)

## Rules
1. Be kind and school appropriate.
2. Don't delete other people's content (Unless you're improving upon it, and even then **ASK**).
3. Make a folder for your files when making or uploading multiple files - this will keep the project nice and organised. (The commands below show how to do this, look at the lines that contain WHATEVERYOUWANT)
4. Don't edit the README file.
5. NO ZIPBOMBS PLEASE

## Making a contribution
1. Create a [Github account](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github).
2. [Set up Git](https://docs.github.com/en/get-started/git-basics/set-up-git).
3. Fork the repository on Github.
4. Clone your fork locally.
FOR THE COMMANDS BELOW WHATEVERYOUWANT SHOULD REMAIN THE SAME (REPLACE WITH WHATEVER YOU WANT)
```bash
git clone https://github.com/YOURUSERNAME/bvdlcoidetwf.github.io.git
cd bvdlcoidetwf
mkdir WHATEVERYOUWANT
cd WHATEVERYOUWANT
(NOW CREATE WHATEVER YOU WANT IN THIS FOLDER THIS IS NOT A LINE TO RUN IN YOUR TERMINAL.)
```
4. Make your changes in the text editor of your choice and commit them.
5. Push your changes to origin.
6. Open a [pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request).

## Tips
Check out [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for information on how to properly name your commits.
